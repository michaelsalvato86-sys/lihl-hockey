# LIHL third party licenses

## Currently shipped (verify before any release)
- three.js (three.min.js and example shader and composer scripts): MIT.
- Quaternius character models and rig: CC0 per the vendor (models/). Confirm against the pack download page when adding more.
- Roster photos and league data come from the lihockey.org site (admin supplied), not open source.
- Fonts, audio: audio is synthesized in code (audio.js), no samples.

## Candidates from the research (none integrated)
Adopt only after reading the LICENSE file: Yuka (MIT), planck.js (MIT), glTF-Transform (MIT), Blender glTF-Blender-IO (Apache-2.0), Poly Haven (CC0), Quaternius Universal Animation Library (CC0 per site), Kenney (CC0 per site), MortimerGoro/AirHockeyWebGL (MIT), dweis/verold-airhockey (MIT).
Study only, do not copy code: wolfrats/hockey (GPL-3.0), librcsc (LGPL-3.0), digitizdat/ski (GPL-3.0).
Rejected: unlicensed repositories, leaked or decompiled game sources (open-ice, NHLHockey), ZenGM (license forbids playable forks).
See docs/research/ for the per-repository table and the items each agent could not verify.
